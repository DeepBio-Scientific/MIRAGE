# Paper: *FamBench: Protein–Ligand Affinity Models Are Inflated by Protein-Family Redundancy*

Build the PDF:

```bash
make            # pdflatex + bibtex + pdflatex x2
```

## Contents

- `fambench.tex` — the paper source
- `references.bib` — bibliography (28 refs)
- `figures/` — the four figures (PDF), regenerated by `make_figures.py`
- `predictions/` — per-method prediction CSVs used in the paper
  (`id,prediction`; compatible with `fambench score`)
- `results/` — the computed result JSONs (`redundancy_results.json`,
  `temporal_results.json`)

## Reproducing the numbers

Every table and figure is reproduced by the FamBench harness from the released predictions:

```bash
# redundancy arm, any method:
fambench score redundancy predictions/nesso1_redundancy.csv
fambench score redundancy predictions/rf_qsar_redundancy.csv

# regenerate the shallow baselines from scratch (family-disjoint CV):
python ../scripts/train_baselines.py --out-dir predictions/
```

The co-folder predictions (`nesso1_*`, `boltz2_*`) were produced by running the public
Nesso-1 and Boltz-2 weights at default settings; see the paper's Experimental Setup.

## Headline result

| method | overall *r* | novel-family *r* | leakage slope (*t*) |
|---|---|---|---|
| Nesso-1 | 0.588 | 0.324 | −0.109 (−7.5) |
| Boltz-2 | 0.467 | 0.308 | −0.139 (−4.3) |
| RF-QSAR (family-disjoint) | 0.479 | **0.411** | +0.008 (0.6) |
| ligand-kNN (family-disjoint) | 0.407 | 0.350 | −0.002 (−0.1) |

Co-folding accuracy scales with protein-family redundancy; matched controls that cannot
memorize the family are flat and win on novel families. On a novel post-cutoff target,
neither co-folder beats molecular weight.
